# FRESHA — Grocery Commerce Basic Website

Pages:
- index.html — Home
- shop.html — Grocery catalogue + category filtering
- product.html — Product detail
- lists.html — Repeat shopping lists
- delivery.html — Delivery slots + subscription concept
- checkout.html — Account-free demo checkout
- login.html / signup.html — Standalone account UI only

Uses the requested assets/css and assets/js structure. Cart is localStorage-based; authentication and payment are intentionally not connected.
